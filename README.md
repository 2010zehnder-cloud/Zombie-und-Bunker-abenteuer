# ☢️🧟 Bunker 45

Ein Überlebensspiel im Browser: **Atomkrieg** oder **Zombie-Apokalypse**.

## So wird gespielt

1. **Katastrophe wählen**: Atomkrieg oder Zombies.
2. **Packen**: Die ganze Familie ist automatisch im Bunker. Du suchst in Ruhe 12 Dinge aus (Suppe, Wasser, Axt, Radio …) oder lässt per 🎲 zufällig packen.
3. **Optional, Action-Modus**: Wer will, rennt stattdessen selbst 45 Sekunden durchs Haus und sammelt Familie und Vorräte ein (4 Plätze, alles braucht 1 Platz). Bei den Zombies bricht nach ein paar Sekunden einer ins Haus ein.
4. **Im Bunker**: Jeden Tag gibt es ein Ereignis mit Entscheidungen, du verteilst Suppe 🥫 und Wasser 💧, behandelst Kranke 💊 und schickst Leute auf Ausflüge nach draußen.
5. **Überlebe bis Tag 40** oder finde einen anderen Ausweg.

## 12 Enden

Der Konvoi, Notlager Nord, Die Tunnelstadt, Die Asche-Wölfe, Der letzte Hubschrauber, Das Heilmittel, Die Festung, Zurück ans Licht, Der letzte Mensch, Einer von ihnen, Stille im Bunker und Die Luke fiel zu. Entdeckte Enden werden im Browser gespeichert.

## 🎥 Zuschauer-Modus

Im Menü einschalten: Die Antworten bekommen die Buchstaben A, B, C mit einem 20-Sekunden-Balken. So kann der Chat bei TikTok- oder Twitch-Livestreams abstimmen, was passiert.

## Starten

`index.html` im Browser öffnen. Es muss nichts installiert werden.

Steuerung: WASD oder Pfeiltasten, auf dem Handy dorthin tippen, wo man hinlaufen will.
